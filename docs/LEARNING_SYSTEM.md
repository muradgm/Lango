# Lango — Learning System

## Learner model

Track six dimensions:

### Linguistic state
Each meaningful item can progress through:

Unknown → Exposed → Recognized → Understood → Recallable → Usable → Automatic

### Communication state
Track capability by situation, including comprehension, speaking and confidence.

### Error model
Track recurring patterns and prioritize by frequency, severity, communicative importance and recurrence.

### Learning behavior
Infer which formats, session lengths, timing and correction styles actually produce retention and completion.

### Life context
Track declared goals, urgency, upcoming situations and long-term curriculum.

### Register and identity
Model preferred register by situation: formal, neutral, everyday, casual, regional/social where appropriate.

## Daily Engine

The Daily Engine selects the highest-value next activity using:

- goal relevance
- real-world urgency
- weakness
- forgetting risk
- communication value
- readiness
- transfer potential
- available time

The formula is a decision framework, not a fixed scoring implementation.

## Correction policy

- Fluency mode: defer minor corrections.
- Accuracy mode: correct aggressively.
- Balanced mode: system chooses.
- Exam mode: evaluate against explicit criteria.

## Cultural/pragmatic learning

Language knowledge includes discourse particles, intonation, hesitation, implication, politeness, conversational distance, humor, register and regional/social variation.

Example: German “tja” should be modeled as a context-dependent discourse marker rather than a one-word translation.

## Adaptive depth

The same question should receive an explanation appropriate to the learner's level and requested depth.

## Evaluation

M0 must measure whether:
- learners complete sessions
- targeted items are retained
- speaking/listening performance improves
- recommendations feel relevant
- users voluntarily use Ask/Talk
- corrections are perceived as useful rather than disruptive

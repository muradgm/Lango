# Lango — Product Definition

## Product thesis

Lango is a mobile-first adaptive language-learning and communication system. It teaches the language a learner needs for the life they are living, while preserving a structured CEFR path.

Core loop:

**Observe → Diagnose → Teach → Practice → Test → Remember → Adapt**

## First product

- Android-first
- German-first
- Real device testing from the beginning
- Structured A1–C1 learning path
- Goal-driven learning for travel, work, study and settling
- Instant help for concepts, words, phrases and pronunciation
- Everyday spoken language, register and pragmatic/cultural context
- Adaptive daily sessions
- Conversation and pronunciation practice
- AI-generated media later, after the core learning loop proves useful

## UX principles

1. Maximum user control; intelligent system guidance.
2. Mobile-native, not desktop UX compressed onto a phone.
3. Real communication over isolated phrase memorization.
4. Recognition and active production are separate states.
5. Correct what matters; do not interrupt fluency unnecessarily.
6. Personalization should be evidence-based, not based on simplistic “learning styles”.
7. Every interaction can become learning data.
8. The app should explain language at the learner's current depth.

## M0 — Pocket Tutor

The first milestone proves:

**Onboard → establish level/goal → generate a 10–15 minute session → practice → give useful feedback → update learner state → change the next session.**

Initial primary surfaces:

- Today
- Learn
- Talk
- Ask
- Real Life

Non-goals for M0:

- social features
- leaderboards/economy
- multi-language rollout
- generated video as a core dependency
- complex cloud sync
- large content marketplace

# Lango

**Adaptive language learning for the life you actually live.**

Lango is a mobile-first Android language-learning system built around user goals, real-world communication and an evolving learner model.

## Current focus

**M0 — Pocket Tutor**

German-first. Android-first. Real-device-first.

The first product loop:

Onboard → Diagnose → Learn → Practice → Feedback → Remember → Adapt
